# GymNote — Марк и Лера

Веб-приложение (Telegram Mini App + PWA) в стиле нативного iOS-минимализма для тренировок в зале. Работает прямо внутри Telegram с личным облаком (`Telegram.WebApp.CloudStorage`) у каждого пользователя — без токенов, паролей и серверов.

## Возможности
- **Личное облако Telegram (у каждого своё)** — при открытии через Telegram-бота данные автоматически сохраняются в личное облако Telegram и синхронизируются между iPhone, iPad и Mac. Работает тактильная отдача (HapticFeedback), подстраивается цвет шапки Telegram под светлую/тёмную тему и есть кнопка **«Поделиться тренировкой в Telegram»**.
- **Профили Марк / Лера** — при первом запуске в Telegram профиль подбирается автоматически по имени аккаунта, также доступен быстрый переключатель в шапке.
- **Дни тренировок (День 1 / День 2 / День 3) + таймер отдыха** — компактная верхняя строка с днями и таймером `90с`, раздельный учёт веса в каждом подходе (повышение веса на 2-м или 3-м подходе фиксируется отдельно).
- **Персональный подбор схемы прогрессии** — стартовый вес, рост и активность → расчёт ИМТ и подбор схемы (включая **«Похудение + тонус, ягодицы и форма»** для Леры, рекомпозицию, массу и силовую базу).
- **97 упражнений, тренажёров, кардио и упражнений со своим весом** — поиск по русским и английским названиям, сленгу и сокращениям (`дорожка`, `лестница`, `stairmaster`, `планка`, `pec deck`, `rdl`, `твб`, `жн`), добавление всегда на русском языке, краткая инструкция **«Как делать»** для каждого упражнения.
- **97 уникальных анимированных схем (1-в-1 без единого повтора)** — точная зацикленная визуализация каждого тренажёра, кардио и упражнения со своим весом (работает офлайн).
- **Автоматическая адаптация при добавлении** — базовые, изолирующие, свой вес, статика в секундах и кардио в минутах/уровнях подстраиваются под вашу схему и параметры тела.

## Как подключить в Telegram за 1 минуту (один раз)
1. Откройте **@BotFather** в Telegram и отправьте `/newbot`.
2. Придумайте имя (например, `GymNote`) и username (например, `mark_lera_gym_bot`).
3. Отправьте `/mybots` → выберите бота → **Bot Settings → Menu Button → Configure menu button**.
4. Вставьте URL приложения: `https://bexaf3163.github.io/Gym-Training-/` и название кнопки (например, `Тренировка`).
5. Откройте бота у себя и перешлите ссылку на бота Лере — у каждого автоматически будет своё личное облако Telegram!

## Большая кнопка на всю ширину чата (опционально, бесплатно)
Готовый скрипт лежит в `bot/cloudflare-worker.js`:
1. Откройте [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages → Create Worker → Deploy → Edit code**.
2. Вставьте код из `bot/cloudflare-worker.js` и нажмите **Deploy**.
3. В настройках воркера (**Settings → Variables and Secrets → Add → Secret**) добавьте переменную `BOT_TOKEN` с токеном из `@BotFather`.
4. Откройте в браузере `https://<ваш-воркер>.workers.dev/setup` — webhook и кнопка настроятся автоматически.
5. Отправьте `/start` в бот — появится приветствие и большая постоянная кнопка **«🏋️ Открыть GymNote»** на всю ширину экрана.
